❓ Questions fréquentes

Retrouvez ci-dessous les réponses aux questions les plus posées.

❓ Qu'est-ce que DevPortfolio ?

DevPortfolio est une plateforme permettant de consulter, partager et gérer des projets de développement informatique.

❓ Comment créer un projet ?

Depuis la page d'accueil, cliquez sur Créer un projet, remplissez les informations demandées puis validez.

❓ Comment débloquer un projet ?

Cliquez sur le projet verrouillé puis effectuez le paiement. Le contenu sera immédiatement accessible.

❓ Comment changer mon mot de passe ?

Depuis la page de connexion, cliquez sur Mot de passe oublié puis répondez à vos questions de sécurité.

❓ Comment contacter le support ?

Utilisez le formulaire situé plus bas sur cette page. Un conseiller vous répondra dès que possible.

❓ Comment fonctionne le paiement ?

Le paiement permet de débloquer les projets premium. Une fois validé, l'accès est immédiat.
